# Signed updater setup

The source build intentionally does not contain a fake updater endpoint or signing key. Release CI generates `release/tauri.release.conf.json` from secrets.

Required GitHub Actions secrets:

- `TAURI_SIGNING_PUBLIC_KEY` — public updater key generated by Tauri CLI.
- `TAURI_SIGNING_PRIVATE_KEY` — private updater signing key/path/content.
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — password if the private key is encrypted.

Optional Authenticode signing secrets:

- `WINDOWS_CERTIFICATE` — base64 PFX.
- `WINDOWS_CERTIFICATE_PASSWORD` — PFX password.

Generate updater keys locally:

```powershell
npm run tauri signer generate -- -w "$HOME/.tauri/nook.key"
```

Do not commit the private key. Keep the same updater key for future releases; existing installs trust that key.
